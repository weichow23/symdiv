# Exploratory integration: SMT advice before a remote request

The completed fixed-resource comparison shows that inexpensive SMT advice can
match historical neural discovery and cover five of six new stress positives
under the charged 128-state cap. Integrate that control into the local-first
workflow instead of leaving it only as a comparator.

This is a separately frozen, post-study extension on the same five already
studied timing cases, with three fresh trials each. It is not held-out evidence.
Keep the 30-second actual deadline, two-second local threshold (checked between
16-pop batches), and 12-second request floor. First compute the existing bounded
SMT advice, then explore its preferences locally. If no advice is returned, use
the existing portfolio. Request the model only if the frontier remains open and
the time condition is met. No source-level safety conclusion comes from the
summary or from skipping a request. All summary and verification work is timed.

All 15 trials and any failures are retained. New calls share the original
80-attempt and observed-token limits, including invalid-clock costs. Comparisons
with the preceding five-method timing cohort are descriptive: this additional
arm runs afterward rather than being newly interleaved with all controls. The
complete main cohort remains unchanged. Request count and returned dispositions
are central outcomes; medians on five selected programs are not a general speedup.
